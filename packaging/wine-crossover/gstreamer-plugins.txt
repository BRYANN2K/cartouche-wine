# The GStreamer plugins Cartouche Wine ships, one per line as
#   <module> <meson option that builds it, or - when always built> <plugin>
# build-gstreamer.sh enables exactly these options, and build.sh copies each
# libgst<plugin> into lib/gstreamer-1.0. Every one is LGPL; nothing from the
# GPL or patent-restricted options (x264, x265, openh264, faad, a52dec, dts,
# mpeg2dec) is built. Wine's winegstreamer needs the first group by name
# (create_element in dlls/winegstreamer); the rest decode what games ship.
